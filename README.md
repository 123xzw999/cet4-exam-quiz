## 功能

- **四种试卷模式**：整卷考试 / 听力部分 / 阅读部分 / 主观题部分
- **按真卷顺序排列**：Part II → Section A/B/C → Directions → **原文** → 题目（单栏连续流）
- **阅读原文直接内联在题目之前**，和真卷一样；可折叠，可随时展开
- **听力原声在线播放**：HLS 流媒体，27 套独立音频 + 19 套共用音频，**46 套全可播**；
  8 个分段按钮（Section A/B/C 各篇）可一键跳到对应听力段落
- **即时判分**：点选项立刻判对错，正确项标绿、错误项标红
- **逐题解析**：按解析册的分类分区展示，同义替换处自动高亮
- **答题卡**：按题型分组，答对绿 / 答错红 / 未答灰，点击跳题
- **主观题**：写作（Part I）+ 翻译（Part IV），可保存草稿，一键展开参考范文 / 参考译文 / 逐句解析
- **成绩报告**：答对 / 答错 / 未答 / 正确率 / 客观题折算（满分 497.5）
- **进度与统计**：每套卷进度条、累计正确率、错题自动收录
- **快捷键**：`A–D`（匹配题 `A–P`）选项、`←` `→` 切题、`D` 开关透明模块
- 答题记录、错题、收藏、手写笔迹全部存在浏览器本地（localStorage）

## 特色功能：透明模块

右下角 **「透明模块」** 按钮，点一下：

1. 整个页面被一层**完全透明的玻璃层**笼罩 —— 不模糊、不变暗、**不改变网站可视度**；
2. 这一层上可以**直接手写**（鼠标 / 触屏 / 手写笔均可），用来圈重点、划句子、记笔记；
3. **按钮和工具栏所在的那块区域不会被笼罩** —— 画布用 `clip-path` 在那里挖了洞，
   而且指针落在该区域时不会落笔；
4. **再按一下按钮**，透明模块消失，笔迹保留。

工具栏：5 种颜色（含黄色荧光笔）、3 档粗细、橡皮、撤销、清空、存图 PNG、**穿透**
（开启后点击可穿过涂层去操作页面，边写边刷题）。

笔迹**按题保存**：切到别的题再切回来，笔记还在。

```

├─ css/style.css              主样式（外围粉色渐变 / 题目区纯白）

├─ js/app.js                  主逻辑（登录 / 首页 / 考试 / 刷题 / 判分）
```
